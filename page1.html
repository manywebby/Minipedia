📖 About Minipedia — Beta 1.7 🔮

Minipedia is a private collaborative wiki — a free, internal knowledge base where users can create, edit, and read pages written in Markdown.

Core features: page creation & editing · revision history · feedback & comments · flashcard sets (flip, write, test modes) · Study assistant · group chat · search · activity feed · user profiles · dark mode · offline caching · admin tools.

Beta 1.7 additions: expanded Shop (5 tabs) · bulk token discounts · power-ups (XP Boost, Coin Doubler, Streak Shield, Page Boost) · display titles & profile badges · custom cursors & page skins · coin refund on tutor errors · /gift-users — Dan can gift coins, gems, tokens, or 1-day Premium Tutor to any user.
